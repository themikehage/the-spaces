# Changelog

All notable changes to **Spaces** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-24

### Added

- Open-Source Foundations release.
- Added MIT License and SPDX headers across all source files.
- Added GitHub Actions CI pipeline (`ci.yml`) and Release pipeline (`release.yml`).
- Added TurboRepo configuration (`turbo.json`) and unified root scripts (`check-license`, `typecheck`, `lint`, `build`, `test`).
- Added central `.env.example`, `docs/self-hosting.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, and `SECURITY.md`.
- Added enhanced `GET /api/health` diagnostic endpoint.
